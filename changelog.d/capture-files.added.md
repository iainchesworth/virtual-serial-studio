**Traffic can now be recorded to a file with every byte and an exact time.** `vss_cli capture <topology.json | --uri=...> --out=FILE [--format=cap|csv|jsonl] [--port=NAME] [--seconds=N]` writes each transfer with its time in milliseconds from the start of the capture, the port it belongs to, a direction (`R` is bytes the port received, `W` is bytes written to it) and all of its bytes. The time is the one the engine read when the bytes moved, on one clock for every port, so a port whose other end is on another computer is stamped here, not by the remote machine. `.cap` is the plain `[ms] R|W 0x..|0x..` text format; `.csv` and `.jsonl` also carry the port and the absolute start time. In Advanced, the monitor has an **Export capture** button next to **Export** that writes the visible rows through the same writer, with every byte and the engine's own time instead of the preview and the time the window received them. The existing text export is unchanged. The studio library gains `vss::capture_writer`, `vss::capture_session` and `vss::read_capture`.

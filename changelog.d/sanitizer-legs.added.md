**The sanitizers run in CI.** The `linux-asan-ubsan` and `linux-tsan` presets build with Clang at -O1 through the shared `IclSanitizers` module, which also stops at the first finding. AddressSanitizer with UBSan runs on every pull request, and ThreadSanitizer runs for merge-queue entries and pushes to `develop`. The old `VSS_SANITIZE` option is gone: nothing ever used it, so it built no instrumented binary.

**The topology parser and the endpoint URI parser are fuzzed.** Each has a libFuzzer harness with a seed corpus and a `regressions/` directory under `libs/<lib>/fuzz/`. The corpus and regression files are replayed by two CTest tests in every build and by a `Fuzz regression replay` job on every pull request, and a new `linux-fuzz` preset (Clang, AddressSanitizer and UBSan at -O1) builds the fuzzers themselves. A `Fuzz` workflow fuzzes for 60 seconds a target on every push to `develop` and for 10 minutes a target each night, keeps the working corpus between runs, and opens a `nightly-analysis` issue when a nightly run finds a crash.

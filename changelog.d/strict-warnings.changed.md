The build now uses the shared `icl::warnings` set, which adds `-Wconversion`, `-Wsign-conversion`, `-Wold-style-cast`, `-Wdouble-promotion`, `-Wimplicit-fallthrough` and `-Wformat=2` on GCC and Clang. Warnings are errors in every build, so the `VSS_WARNINGS_AS_ERRORS` option is gone. GCC's `-Wnull-dereference` stays off because it reports false positives inside Boost.Asio. The conversions the new set found are fixed.

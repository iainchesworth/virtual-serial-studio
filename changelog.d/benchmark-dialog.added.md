**The benchmark runs from the window.** In Advanced mode, Tools → Benchmark sends 1, 10 or 100 MB from one port and counts what arrives on another, with a progress bar, a Cancel button, and a result that says Passed or Failed and how many bytes were lost. The measurement is now a library function, `vss::run_benchmark`, which `vss_cli bench` uses too, so the two give the same figures.

**The ports list says what is on the other side of a port.** Where Studio can tell, a port shows the baud rate and framing a program set ("Program set 19200 7E2": Windows driver ports and Linux and macOS pseudo terminals), a listener shows how many clients are connected or "No remote connected", and a port whose speed differs from the others on its link is marked "Differs from X in baud rate or framing", in the window and as a warning from `vss_cli run`. In the engine, `endpoint_info` gains `peer_format` and `clients`, `transport` gains `peer_format()` and `client_count()`, and `studio::format_mismatches()` lists the links that disagree. Nothing changes for a port that cannot tell.

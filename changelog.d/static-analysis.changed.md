**Static analysis covers the whole tree and has a local command.** clang-tidy, cppcheck and zizmor now report to GitHub code scanning, on pull requests as well as nightly, and clang-tidy reads the Qt GUI and the tests as well as the libraries. MSVC code analysis builds the GUI and the tests, and CodeQL adds its quality queries. `python tools/analyze.py` runs each analyser locally, writes the same SARIF files, and the `windows-msvc-analysis` preset runs PREfast.

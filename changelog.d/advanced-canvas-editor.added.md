**Advanced mode is now a canvas editor.** A toolbox beside the topology holds ports (Port, Fixture, Loopback, Device, Network) and bundles (Pair, Split, Join, Bus, Switch, Redirect, Monitor, Share, Bench). Drag a tile onto the canvas, or press Enter on it, and choose in the Add sheet whether each end is a new port, a new fixture, a loopback or a port already there, so a pair of two fixtures is one step. Drag from the handle on a port's edge to another port to link them two-way, one way or as a monitor; drop on empty canvas to add a new port there. Right-click a port for Settings (baud rate, data bits, parity, stop bits, flow control and timeouts), Duplicate and Delete; right-click a link for its delay, jitter and policy. Select several items with Ctrl+click, a rubber band or Ctrl+A, and every change on the canvas can be undone, deleting ports included. An empty setup in Advanced mode opens the empty canvas instead of the launcher. A port's serial settings can now be changed after it is made: a fixture or a device is opened again with them, and a virtual port saves them for the program that opens it.

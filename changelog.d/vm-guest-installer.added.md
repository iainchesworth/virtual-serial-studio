**The VSS guests install and snapshot themselves.** `tools/vm/install-guest.ps1` starts a guest made by `new-vm.ps1`, works round the restart that would otherwise make Windows Setup begin again, waits for the guest to power itself off, checks it through VMware Tools with the test credentials, and only then takes the `clean` snapshot. `new-vm.ps1` boots patched copies of the Ubuntu and Windows 10 ISOs that answer the two prompts nobody can press at a test guest (`patch_ubuntu_iso.py`, `patch_windows_iso.py`), puts the Windows disks on SATA, and the Windows answer file answers the product key page. The Ubuntu password hash no longer carries a carriage return.

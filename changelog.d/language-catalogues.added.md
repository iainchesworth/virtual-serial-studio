**The window can be shown in French, Spanish, German, Hebrew, Yiddish, Japanese, Simplified Chinese and Arabic.** Each language has a catalogue of the 903 distinct texts that can be translated so far, and the program uses it when the system's language is one of them. They are machine translations that no speaker has reviewed, which each catalogue and `docs/i18n.md` say. A test fails if a catalogue is missing a string, has an unfinished or empty translation or changes a placeholder. Texts in the About, setup check, troubleshooting, settings, topology and Advanced tool windows are not covered yet and stay English.

**The window can be shown in French, Spanish, German, Hebrew, Yiddish, Japanese, Simplified Chinese and Arabic.** Each language has a catalogue of the roughly 1130 distinct texts of the window, and the program uses it when the system's language is one of them. They are machine translations that no speaker has reviewed, which each catalogue and `docs/i18n.md` say. A test fails if a catalogue is missing a string, has an unfinished or empty translation or changes a placeholder.

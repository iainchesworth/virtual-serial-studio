**Releases are built as packages for Linux, macOS and Windows.** A `vMAJOR.MINOR.PATCH` tag builds `vss_gui` with the Qt libraries it needs and `vss_cli` into one archive for each system, runs the installed command line tool, and hands the archives to the shared publish workflow for checksums, GPG signatures, a software bill of materials and attestations. The same build runs every Monday and on request without publishing, so the install rules are tried before a tag. Installing now has two components: `runtime` for the programs and licence texts, and `development` for the libraries and headers. `docs/releasing.md` describes the steps and what the owner provides.

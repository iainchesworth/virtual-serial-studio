**Three analysis engines run every night on `develop`.** CodeQL scans the C++ (built with GCC), the Python tools and the workflows; MSVC `/analyze` checks the Windows build; and clang-tidy adds the bugprone, concurrency, performance, portability, misc and clang-analyzer groups to the naming rules the pull request gate runs. None of them gates a merge, and a failure opens or updates one `nightly-analysis` issue. The clang-tidy run found real findings, which are fixed: several functions took strings by value and now take them by const reference, a few `std::move` calls on trivially copyable options were removed, `endpoint_options` sizes are computed in `std::size_t`, and two vectors reserve their capacity.

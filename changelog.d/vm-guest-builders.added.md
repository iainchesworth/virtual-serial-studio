**The VSS guests can be rebuilt from the install ISOs.** `tools/vm/new-seed.ps1` writes the answer disc for an unattended install of Windows 10, Windows 11 or Ubuntu 26.04 to `%USERPROFILE%\.vss\seeds`, outside every repository, reading the guest credentials from the shell and printing neither. `tools/vm/new-vm.ps1` checks the ISO against `tools/vm/iso-hashes.json`, writes the disk and VMX without starting the guest, and never overwrites an existing one. `tools/vm/guest/setup-guest.ps1` installs VMware Tools, turns on test signing and powers the Windows guests off for the `clean` snapshot. Dry-run tests of both scripts run under ctest with placeholder credentials.

**The GUI has journey tests.** Five tests send key presses and mouse clicks through QTest to the real main window and its dialogs, over the in-memory backend: give my program a serial port (by keyboard), connect two programs, watch traffic, run an action from the command palette, and remove a port with the Delete key. They run as the `gui_journeys` CTest test (label `ui`) wherever Qt and Qt Test are installed, and a dialog that never opens fails the test after eight seconds instead of hanging it.

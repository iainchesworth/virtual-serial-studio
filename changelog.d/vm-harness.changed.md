**The VM harness reports what the guest did and works on the VSS guests only.** `tools/vm/vmrun.ps1` exited with 0 whatever the guest command returned; `run` now exits with the guest's exit code, and fails if the guest reports none. It refuses any VM that is not a VSS guest, never creates a snapshot on its own, hides the password in everything it prints, passes the guest credentials before the `vmrun` command as `vmrun` documents, and gains `copy-from`, `screenshot`, `snapshots` and `wait-tools`. `tools/vm/matrix.json` lists the three VSS guests, `tools/vm/test-vmrun.ps1` checks the script against a stand-in for `vmrun`, and `docs/vm-testing.md` describes the guests.

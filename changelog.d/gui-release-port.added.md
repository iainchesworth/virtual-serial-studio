**Advanced mode has Release port for a Studio driver port that a program holds.** The Inspector shows **Release port...** when the Studio driver reports that a program has the port open. The dialog names the program and its process, says how long no data has passed on the port (a fact; it does not claim the program is stuck), and offers two ways, each confirmed by the one button: take the port back (the program keeps running, its connection to the port stops working and another program can open the port at once) or end the program. Studio ends only your own programs unless it was started as administrator, and says so for another user's. The ports library gains `vss::revoke_driver_port`, `vss::describe_process` and `vss::terminate_process`, and the studio library gains `studio::revoke_port`, `studio::driver_holder` and `studio::driver_ports`.

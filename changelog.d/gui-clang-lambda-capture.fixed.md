**The GUI builds with AppleClang and Qt installs on Windows in CI.** Eight lambdas in `gallery.cpp`, `json_editor.cpp` and `shell_window.cpp` captured `this` without using it, which Clang rejects under `-Werror=unused-lambda-capture`; the macOS GUI build had never run in CI, so nothing had caught it. `.github/toolchain-versions.json` now pins the `aqtinstall` build that knows the Qt 6.12 repository layout on Windows, as the Qt set-up action expects.

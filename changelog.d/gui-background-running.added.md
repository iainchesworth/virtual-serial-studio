Closing the Studio window no longer stops the ports. Studio stays in the
notification area and keeps them running until you quit it, and starting Studio
again brings back the same window. The running setup is kept by itself and
starts again after a restart, a sign-out or a crash. After a Quit a banner
offers to start it again. Settings has a new Running page. It can make closing
quit, as before, and it can start Studio hidden when you sign in (Windows and
Linux).

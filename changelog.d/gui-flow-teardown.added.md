**Remove a whole setup in one step, and add programs to a share later.** Remove setup closes a linked pair, shared device or attached device with all its ports, from the toolbar, the Edit, Ports and Topology menus and the command palette. Delete on a port in a setup offers only that port or the whole setup, and the confirmation names every port that closes. Add a program port (Topology menu) and Add another program (last step of the Share wizard) add a program without touching the ports already shared, and the wizard now says the number can change later.

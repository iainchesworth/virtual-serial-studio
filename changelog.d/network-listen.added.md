**Wait for other computers to connect.** A network endpoint can now act as a server: `tcp-listen://host:port` accepts any number of TCP clients and sends them everything that is written to it, and `udp-listen://host:port` reads datagrams from anyone and replies to the senders it has heard from lately. The network dialog's server choice, which was switched off, now works for TCP and UDP, and `vss_cli bridge` accepts both forms. RFC 2217 still connects only.

**The platform matrix tests `vport` and the release package, and a guest cell runs with one command.** `tools/matrix/run_cell.py` gains T8, which starts `vss_cli vport`, checks that the stable links appear and carry bytes, that a second `vport` is refused the names a running one holds, that links left by a killed process are replaced, and that SIGTERM removes them. It also gains T9, which unpacks a release archive (`--package`) with no build environment and runs `vss_cli selftest` and `vss_gui --version` from it. `tools/vm/guest-cell.ps1` takes a guest from the `clean` snapshot to the evidence in one run, with `tools/vm/make-bundle.ps1` and `tools/vm/make-bundle.sh` building what the guest needs outside it. `docs/platforms.md` lists the results.

**The canvas Add sheet no longer comes back when an add fails.** On the Advanced canvas, choosing Add when the add failed closed the sheet and opened a new one with the default names and only a small caption, so it looked as though Add did nothing and the typed name was lost each time. The sheet now stays open with what you typed and shows why nothing was added in a red note, so you can change the name and try again. A failed add leaves nothing behind.

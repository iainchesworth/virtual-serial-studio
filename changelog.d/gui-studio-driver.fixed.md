**The window counts the Studio driver as a virtual port driver on Windows.** A PC with only the Virtual Serial Studio driver no longer sees "com0com was not found": the setup check, the launcher, the pair panel, the share wizard and the port-ready dialog count either driver as ready and say which one was found, with the driver version. The Studio driver makes ports when they are asked for, so a pair or a share needs no free com0com pairs; the share wizard warns only when more programs are asked for than one user can hold (16). The com0com install guidance stays for a PC with neither driver. Ports the Studio driver made are listed as virtual ports, not as devices you can attach or share.

**The line matrix can be edited.** For a mock fixture, Open line matrix and faults in the Inspector now lets you choose which of DTR and RTS drives which of DSR, CTS, DCD and RI on the linked port, or pick a preset, and the change applies at once. The default is still the null-modem cable. The wiring lasts while Studio runs and is not saved in a setup file. The library gains `modem_wiring` in `link_options` and `hub::set_link_wiring`.

**The GUI's text can be translated.** About 440 more strings, among them the launcher, the menus and toolbar actions, the status bar, the ports, inspector, send and monitor panes, the dialogs and the Advanced tools, are now wrapped in `tr()`, so a language catalogue can cover them. Sentences that were built from pieces are single strings with `%1` placeholders, and counts of programs and bytes carry plural forms. The English text is unchanged. Eight lambdas that captured `this` without using it are fixed, because Clang rejects them.

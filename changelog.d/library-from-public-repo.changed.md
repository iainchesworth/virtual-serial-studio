Boost.VirtualSerial is now fetched by CMake from its public repository at the `v0.1.0-beta.1` release tag, so a clean checkout configures with no extra setup. The implicit sibling-folder lookup is gone; set `VSS_VIRTUAL_SERIAL_DIR` to build against a local checkout. CI no longer needs the read-only deploy key, so pull requests from forks build, and the `ENABLE_MACOS` gate is removed so the macOS job always runs.

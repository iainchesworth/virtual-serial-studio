**A port can now act as a scripted device or master.** `vss_cli respond SCRIPT (--uri=URI | --port=NAME)` makes one port answer from a JSON script kept apart from the topology file, so the topology schema does not change. A rule says "when these bytes arrive (exactly, or under a mask), send those bytes after N ms, give or take some jitter"; an optional poll list sends timed steps once or in cycles, which makes the port a master. Bytes are matched as a stream, replies are timed from the moment the request arrived, a seed makes the jitter repeat, and a misspelt key in a script is an error that names it. The studio library gains `vss::responder` and `vss::parse_responder_script`.

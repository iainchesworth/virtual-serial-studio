**CI runs in tiers.** A ready pull request builds Linux GCC and runs ASan/UBSan and the fuzz replay (ThreadSanitizer too when threading code changed). A merge-queue entry adds Windows MSVC, ThreadSanitizer, the Qt GUI build, the performance floors and, when a change can affect them, macOS and the Windows driver. Linux Clang, macOS, coverage, Tracy profiling and the driver run after the merge, one run at a time. `gh workflow run ci.yml --ref <branch>` runs every leg.

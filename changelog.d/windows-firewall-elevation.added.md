**Studio explains Windows Firewall and elevation, and fixes the firewall with one rule you approve.** The Setup check has a *Windows Firewall* row, and the Network endpoint dialog a **Check Windows Firewall for this port** button, that read the firewall rules and say whether other computers can reach a port Studio listens on. When no rule allows it, a dialog shows the one rule Studio would add (this program, one protocol, one port, your local network, the network you are on) and the same rule as a `netsh` command; **Allow in Windows Firewall** adds it through Windows' own permission prompt, in a small `vss_cli` helper, and nothing changes before you press it. A rule that blocks the program, or *Block all incoming connections*, is explained and left alone. The administrator row says whether Windows will ask you to confirm or for a password, and *Restart as administrator* says plainly when you declined the prompt. `vss_cli permissions check` prints the same facts.

Added a shared bus link, `bus`, that puts two to 64 ports on one multi-drop line: every port hears every other and never itself, any kind of port can be a member, and a `join` from the members gives a listen-only tap. A bus carries no modem lines and takes no owner, a port can be on one bus only, and a route that leaves the bus and returns to it is still refused as a loop. It is in the hub (`link_mode::bus`, `hub::bus`), the studio (`studio::bus`), the topology JSON (`"mode": "bus"` with `members`, still version 1), `vss_cli bus`, and the Connect ports dialog, which shows it disabled with "Not available in this build" where the engine has none.

**Mock fixtures can be given faults.** In Advanced mode, select a fixture, choose Open line matrix and faults in the Inspector, and inject a parity error, framing error, overrun, break, hang-up or disconnect. The fixture reports the fault as an error event and stops, and the fault is listed in the history. The studio library gains `studio::inject_fault` for the same purpose; faults are refused for any port that is not a fixture.

**The port list shows the studio's own virtual ports on Linux and macOS.** A pseudo terminal is not in `/dev`, so the list could not see the ports that `vss_cli vport` and the studio make. It now includes the stable links from the link directory, marked as virtual ports and left out once the process behind them is gone. The list also takes USB gadget (`ttyGS`), `tnt` and Bluetooth (`rfcomm`) serial devices, which Qt's own list shows too.

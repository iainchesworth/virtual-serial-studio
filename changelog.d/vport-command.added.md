**`vss_cli vport` makes pseudo terminals with stable names.** `vss_cli vport --name=ttyVSS0,ttyVSS1 --link=ttyVSS0:ttyVSS1` creates a port for each name, prints the stable link an application should open and the pseudo terminal behind it, joins the linked pairs like a null-modem cable, and runs until Ctrl-C or SIGTERM, when it removes its links. A link left by a process that was killed is replaced the next time; a name that a running process holds is refused. The studio takes the same behaviour through the new `studio_options::stable_links` and `stable_dir`, and advertises the link instead of `/dev/pts/N`. `docs/posix-virtual-ports.md` says where the links go and what other programs see, and `docs/windows-com-driver.md` no longer claims that modem lines work on a pseudo terminal.

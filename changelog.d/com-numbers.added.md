**On Windows, a port from the Studio driver can be given the COM number you choose, and the number can be changed afterwards.** Ask for it when the port is made (`vss_cli virtual --com=7`, or `"com_number": 7` on a virtual port in a saved topology) or change it later, as Device Manager's Advanced > COM Port Number does. A number another device has, a real port, com0com or anything else, is refused with a clear message and no port is made. Programs that open a fixed name such as `COM3` then find the same port every run. The number needs the helper service (`vsscom_helper`), for either driver: it claims the number in Windows' COM name database and restarts the port. The ports library gains the optional `com_number` argument of `create_driver_port` and the function `set_driver_com_number`, the studio library gains `create_virtual_port(..., com_number)` and `studio::set_com_number`, and a saved topology gains an optional `com_number`. The Studio window does not offer to choose or edit COM numbers yet.

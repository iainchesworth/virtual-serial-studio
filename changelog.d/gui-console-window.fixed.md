**Starting Virtual Serial Studio on Windows no longer opens a console window beside it.** The program was built for the console subsystem so that `--selftest` could print, which gave every start from the Start menu, Explorer or the sign-in entry a black window that stayed open as long as Studio ran. It is now a Windows-subsystem program. Started from a terminal it still prints `--version`, `--help` and the `--selftest` result there, and a test checks the program's subsystem. In a terminal, `cmd` and PowerShell do not wait for a program of this kind, so use `start /wait vss_gui.exe --selftest` or `Start-Process -Wait` when the exit code matters; test runners that start the program themselves wait as before.

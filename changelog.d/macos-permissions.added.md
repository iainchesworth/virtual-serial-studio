**On macOS the Setup check explains the Application Firewall, Local Network access and the App Sandbox, and the release has what notarisation needs.** When a network endpoint waits for other computers, a *macOS firewall* row reads the firewall state and says that macOS will ask once whether to allow incoming connections (choose Allow), shows the two commands that fix a mistaken *Don't Allow*, and asks you to turn off *Block all incoming connections* if that is on. A *Local Network access* row says where the macOS 15 permission is, because it cannot be read. A *Serial device access* row and a *Confinement* row cover `/dev/cu.*` and the sandbox's entitlements. Studio changes nothing on macOS. The app bundle's `Info.plist` now carries `NSLocalNetworkUsageDescription`, and `apps/vss_gui/macos/` holds the hardened-runtime and sandbox entitlements with `tools/macos/sign-and-notarize.sh`, which the owner runs with their own Developer ID to sign, notarise and staple the release.

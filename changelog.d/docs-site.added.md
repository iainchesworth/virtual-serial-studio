**The documentation is a site.** `mkdocs.yml` builds the pages under `docs/` with MkDocs Material in strict mode. A pull request that changes the documentation builds it and checks that every preset a page names exists in `CMakePresets.json` and that every README badge names a workflow that exists, and a push to `main` publishes it to GitHub Pages once the repository's Pages build type is set to GitHub Actions. The build, test and CI sections of the README moved to `docs/building.md`, `docs/testing.md` and `docs/ci.md`, and the README now has a badge row.

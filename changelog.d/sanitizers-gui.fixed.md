**Every test suite, the GUI included, now runs under the sanitizers.** The pull request gate and the nightly run build the GUI with AddressSanitizer and UBSan (Linux, and MSVC AddressSanitizer on Windows) and ThreadSanitizer, and run all the suites in them. This found two defects in the GUI, now fixed: every accessible-name change leaked a small event object, and the toast manager downcast a toast while it was being destroyed. In a sanitizer build every test timeout is five times longer, and the Windows GUI tests start with the MSVC AddressSanitizer runtime on their path.

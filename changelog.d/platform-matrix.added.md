**The platform matrix runs on hosted runners every night.** `.github/workflows/platform-matrix.yml` builds the GUI preset and runs the suite on Ubuntu 24.04 and 26.04, Windows 2025 and macOS 15 and 26 on Apple silicon and Intel, then runs the cell tests of `tools/matrix/run_cell.py`: two virtual ports exchanging data with a separate process, split and join topologies from JSON, the command-line and GUI self-tests, screenshots in both themes, what the system lists for a virtual port, and a throughput run. Each cell writes a `result-<cell>.json` and its logs and screenshots as an artifact, `tools/matrix/merge_results.py` turns them into the table in the run summary, and a night with a failed or unrun test opens one `nightly-analysis` issue. `vss_cli` now flushes its port table at once so a script can read it through a pipe.

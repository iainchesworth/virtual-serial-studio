**On Linux, a pseudo terminal now shows whether a program has opened it.** The Ports list, the Inspector and the "Why is nothing arriving" check say *Waiting for program* until something opens the port and *Program connected* once it does, and the list looks again once a second. Studio finds this by looking at which processes it may inspect have the device open, so a program run by another user can be missed. On Windows and macOS, and for every port that is not a pseudo terminal, a port still reads Open and nothing is claimed. The ports library gains `vss::peer_open` and the studio library gains `studio::peer_states`.

**A link on the Advanced canvas can be clicked on its line.** The link's bounding box ignored its line segments (a horizontal line has no area, and the code skipped any rectangle without one), so the canvas found a link only near its arrowhead or label and right-clicking a line opened the empty-canvas menu. Clicking a link also now replaces what was selected, as clicking a node does. Before, the ports an Add had selected stayed selected, and Delete removed them instead of the link that was clicked.

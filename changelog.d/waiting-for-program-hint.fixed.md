**A port that is waiting for a program now says which COM port the program has to open, and a new port no longer takes COM1 or COM2.** The Inspector, the Port ready dialog and the "Why is nothing arriving?" check say that the program must open exactly that port, and the Inspector has a Copy name button for it. On Windows with the Studio driver, the window now asks for a COM number above every port the computer already has and never below COM3, instead of the lowest free one, so a program set up for an on-board COM1 or COM2 does not find a port of ours, and a number that Windows keeps for a device that is not plugged in is skipped. It needs the helper service, as a chosen number always has, and the port takes a second or two longer to appear; without the service the number is chosen by Windows as before.

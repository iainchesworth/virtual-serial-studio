- A link can hold what it carries for a set time: `delay_ms`, and `jitter_ms` to vary it either side, on any link mode including a shared bus. It lets you rehearse a reply that arrives at 190 ms or 210 ms, or the extra hop of a network bridge. Bytes of one route keep their order. Left out, a link forwards at once as before. In the engine, `link_options` gains `delay_ms` and `jitter_ms`; the topology file stays version 1.

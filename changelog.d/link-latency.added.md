**A link can hold what it carries for a set time.** Set `delay_ms` on any link, a shared bus included, and `jitter_ms` to vary each chunk by up to that much either side. It lets you rehearse a reply that arrives at 190 ms or 210 ms, or the extra hop of a network bridge. Bytes of one route keep their order, and a link without them forwards at once as before. In the engine, `link_options` gains `delay_ms` and `jitter_ms`; the topology file stays version 1.

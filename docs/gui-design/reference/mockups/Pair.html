Connect two programs

Create a linked pair of ports. Whatever one program sends, the other receives.

Program A opens
COM7
linked both ways, like a null-modem cable
Program B opens
COM8

Names are suggested from free COM numbers. Change them if a program expects a particular name. On Linux and macOS the ports are paths such as /dev/pts/3 and are chosen for you.

Anything COM7 sends arrives at COM8, and the other way round. DTR is wired to DSR and RTS to CTS, as on a standard null-modem cable.
Windows will ask for administrator permission to create this pair.
More options Advanced Signal wiring and port kind. Turn on Advanced mode to change them.

1 Foundations

States, feedback and accessibility behaviour

One vocabulary for port state, one rule for how fast the window answers, and the keyboard and screen reader behaviour of the key controls.

Port state vocabulary
StateMeaningWhat the user does
OpenRunning and able to carry data.Nothing.
Waiting for programThe port exists, but no program has opened it yet.Open the port name in the program, or use Why is nothing arriving?
Program connectedA program has the port open.Nothing.
Studio onlyAn in-process port. Other programs cannot open it.Create a linked pair when another program needs it.
ClosedStopped. No traffic is carried.Reopen it, or remove it.
FailedAn operation failed, for example the device was unplugged or is in use.Read the message, fix the cause, try again.
Keyboard and screen reader behaviour
ControlAnnounced asKeyboard
Port row"terminal, COM7, waiting for program"Up and Down select. Enter inspects. Delete removes.
Copy button"Copy COM7", then "Copied" when pressedSpace or Enter.
Topology node"Port terminal, COM7, in a split link from device"Tab moves between nodes. Arrow keys move a node, so no action needs dragging (2.5.7).

Monitor row"12:04:31.208, device, received 38 bytes"Up and Down. Traffic is not announced unless asked.

Focus order follows reading order: menu, toolbar, ports, topology, inspector, send, monitor, status bar. Dialogs take focus on their first field, return it to the control that opened them, and close on Escape. State changes are announced politely, for example "terminal: program connected".

How fast the window answers
Under 0.1 sFeels instant. No indicator. Copy, toggle, select.
Up to 1 sKeep the flow. Disable the button and show "Creating..." in place.
Up to 10 sShow progress with a Cancel button. Driver install, benchmark.
Over 10 sDeterminate progress, safe to switch away, a message when done.

Live counters refresh at the chosen interval (250 ms by default), never animate and never take focus.

Error message anatomy
Could not open COM3
Another program is using it, or the device was unplugged.
Close the other program, then try again. Or choose a different device.
  1. What happened, naming the operation.
  2. The likely cause, in plain words.
  3. What to do next, as buttons.
  4. Engine text and codes live behind Copy details.
Motion

100 ms for hover and press, 150 ms for disclosure, 200 ms for dialogs (fade and an 8px rise), all ease-out. No bounce or parallax. With the operating system's reduce motion setting, everything is instant.

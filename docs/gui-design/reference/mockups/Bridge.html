Put a device on the network

Share a serial device with other computers over TCP, UDP or RFC 2217.

Share it using

Choose This PC only (127.0.0.1) to test from this machine first.

Other computers can connect to this PC on port 4001 and talk to COM3. Data flows both ways, and the Monitor shows both directions.
Allow Virtual Serial Studio through Windows Firewall, or other computers cannot connect.
Address
tcp://0.0.0.0:4001
Same thing from the command line
vss_cli bridge serial://COM3?baud=115200 tcp://0.0.0.0:4001

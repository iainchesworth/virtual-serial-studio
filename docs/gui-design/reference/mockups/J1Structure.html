About

The Scenarios menu retires. Share and bridge move to Topology and Ports, and the null-modem demo becomes a template, so both levels use the same menus.

Three layers
LauncherBasic

Four jobs, the readiness strip and recent setups. Shown while the studio is empty, and from View, Show launcher.

WorkspaceIntermediate

Ports, topology, inspector, send and monitor. Always the same frame once a port exists.

Power toolsAdvanced

Log, topology JSON, link wiring, owner control, fault injection, benchmark, network endpoints and fixtures.

The switch lives in the status bar and in Settings. Ctrl+K lists hidden tools with a prompt to turn Advanced on. Switching never changes anything already built.

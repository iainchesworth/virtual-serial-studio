Attach a real device

Studio opens the device once. Your programs then open the port Studio creates for them.

Device

The list is read when this window opens. Plug a device in, then choose Refresh.

Device settings

Most devices use these settings. If you see garbled text, check the device's manual.

Studio will open COM3 at 115200 baud and keep it open. Your programs should open the port Studio creates, not COM3.

6 Recover and support

Feedback and error patterns

Each pattern says what happened, why, and what to do. Nothing closes the window or discards the setup.

Device cannot be opened
Could not open COM3

Another program is using it, or the device was unplugged. Close the other program, then try again.

Unsaved changes
Save changes to lab.json?

Your ports and links have changed since the last save. You can turn this prompt off in Settings.

Link refused, would loop
That link would create a loop
Data would travel from device to terminal and back to device forever. Nothing was changed.
Remove a link first, or choose different ports.
